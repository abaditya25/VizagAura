# VizagAura 🌡️

**A locality-level heat and weather awareness dashboard for Greater Visakhapatnam, Andhra Pradesh.**

VizagAura helps people explore local weather conditions, understand potential heat risks, and access practical recommendations to make informed decisions during hot weather.

## 🌍 Live Demo

https://main.d3bj1rlsjcdyx5.amplifyapp.com

## ✨ Features

- **Locality search:** Explore weather information for supported locations around Visakhapatnam.
- **Current weather:** View current weather conditions and relevant measurements.
- **3-day forecast:** Check upcoming weather conditions.
- **Heat-risk screening:** Understand potential heat-related risk based on displayed weather information.
- **Personalized recommendations:** Get practical suggestions based on the conditions shown.
- **Responsive design:** Use the dashboard on desktop and mobile devices.

## 🛠️ Technology Stack

- HTML, CSS and JavaScript
- Open-Meteo API for weather data
- AWS Amplify Hosting for deployment

## 🚀 Run Locally

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Ensure you have an internet connection for the weather API.

No build step is required for this single-file version.

## 🎯 Problem and Impact

Hot weather can affect daily activities, especially for people who work or travel outdoors. VizagAura brings local weather information, short-term forecasts, heat-risk screening, and practical guidance together in one accessible dashboard.

The goal is to help residents make more informed decisions about outdoor activity and heat exposure.

## 📊 Data Source

Weather information is retrieved from the [Open-Meteo API](https://open-meteo.com/).

Weather-based risk screening and recommendations should be treated as informational guidance, not as a medical diagnosis or an official warning.
